# 项目规划文档索引

本目录用于保证“警官学院闯关学习游戏”的目标、范围、节奏和交接信息可追踪。

建议阅读顺序：

1. [01-prd.md](./01-prd.md)：产品定位、用户、核心玩法、功能范围、验收指标。
2. [02-curriculum-map.md](./02-curriculum-map.md)：二年级下册语文/数学知识点与游戏关卡映射。
3. [03-project-plan.md](./03-project-plan.md)：阶段计划、里程碑、人员分工、风险控制。
4. [04-development-standards.md](./04-development-standards.md)：开发规范、内容规范、数据结构、验收流程。

当前原型位于项目根目录，技术栈为 Vite + React + TypeScript，已有欢迎页、登录页、学员仪表盘、地图、案件、Boss 战、结案报告、学习手册、勋章墙等页面骨架。
