# 产品北极星草案

状态：第 1 轮部分已确认  
用途：确认项目“到底要做成什么”，避免开发过程被单个页面效果带偏。

## 1. 一句话定位

已确认方向：

> 一个面向中国小学二年级学生的剧情闯关学习游戏。孩子作为动物城市警探学院的新生，在导师带领下学习语文、数学、英语知识，通过搜集线索、破解案件、击败 Boss，逐步成长为传奇小警探。

内部原型阶段可贴近“疯狂动物城警官学院”的世界观和氛围。对外发布前必须重新确认授权或原创替换方案。

需要确认：

- 是否保留“警探学院”作为主设定。初步确认：保留。
- 是否保留“动物城市”作为主舞台。初步确认：保留。
- 是否强调“官网招募”作为第一入口，还是直接进入游戏地图。已确认：第一入口为警官学院官网招募页。

## 2. 目标用户

主用户：

- 中国小学二年级下册学生。
- 年龄约 7-9 岁。
- 需要短句、明确目标、可视化反馈、低挫败交互。

辅助用户：

- 家长：关心教材贴合、学习效果、时长控制。
- 老师/教研：关心知识点准确、题目质量、难度梯度。
- 开发/内容团队：关心数据结构、交接规范、扩展效率。

待确认问题：

- MVP 优先服务孩子、家长，还是老师？已确认：孩子优先。
- 是否需要家长陪伴场景？
- 是否以“课后练习”为主，还是“兴趣游戏”为主？

## 3. 核心体验循环

已确认：MVP 第一版以完整破案学习闭环为核心验证目标。

待细化循环：

1. 看到学院招募，产生加入动机。
2. 创建小警探身份。
3. 进入动物城市地图。
4. 选择一个案件。
5. 阅读短剧情，明确任务目标。
6. 完成学习题目，获得线索。
7. 使用线索排除嫌疑人。
8. 进入 Boss 综合挑战。
9. 结案，获得 XP、勋章和导师评价。
10. 解锁下一片地图或下一节课程。

需要确认：

- 是否必须有“推理真凶”环节。
- Boss 是具体反派，还是抽象障碍，例如迷雾、错误密码、混乱装置。
- 结案报告面向孩子为主，还是也要给家长看。

## 4. 第一版成功标准

基于“完整破案学习闭环”的成功标准草案：

- 孩子能在 2 分钟内进入第一个案件。
- 首个案件能在 8-12 分钟完成。
- 首个案件先做单学科闭环，避免三门课混合导致体验和难度失焦。
- 题目不是孤立练习，至少 80% 题目与剧情线索有关。
- 每道题都有提示和解释。
- 首个案件完成后，孩子能清楚知道自己获得了什么成长。
- 页面在桌面和平板尺寸不重叠、不依赖图片里的文字完成交互。

需要确认：

- MVP 是否必须支持手机。
- MVP 首个试玩对象是谁：孩子、家长，还是内部团队。
- 是否需要量化学习效果，例如正确率、错题、知识点掌握。

## 5. 不做清单草案

第一版建议暂不做：

- 真实多人社交。
- 排行榜。
- 付费系统。
- 老师后台。
- 云端账号。
- AI 自由对话。
- 复杂 3D 城市。
- 长时间连续任务奖励。

需要确认：

- 是否需要保留“账号登录”的概念。
- 是否需要家长报告作为 MVP 必选项。
- 是否需要语音朗读和音效。

## 6. 北极星验收问题

在进入 UI 和开发前，需要能回答：

- 这个项目更像“学习游戏”，还是“游戏化练习系统”？
- 孩子为什么愿意打开第二次？
- 家长为什么认为它有价值？
- 老师/教研如何判断题目不偏离教材？
- 新增一个案件时，开发、内容、视觉分别要交付什么？
