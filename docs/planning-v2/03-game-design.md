# 游戏框架草案

状态：首案方向已确认，具体剧情和知识点待确认  
用途：定义“游戏像什么”，在页面设计和开发前先确定玩法骨架。

## 1. 已确认边界

- 世界观：疯狂动物城内部原型。
- 第一入口：疯狂动物城警官学院官网招募页。
- MVP 核心：完整破案学习闭环。
- MVP 主用户：小学二年级孩子优先。
- 首个完整案件：单学科案件。
- 首个案件学科：数学。
- 首个案件类型：校园训练案。

## 2. 游戏主线草案

孩子第一次进入时，不是直接刷题，而是收到警官学院的新生招募邀请。

主线草案：

1. 孩子浏览警官学院官网，了解“新生探员招募”。
2. 孩子点击加入学院，创建自己的小警探档案。
3. 导师欢迎新生进入学院训练场。
4. 学院发布第一项训练案件：用数学能力修复训练系统、收集线索、完成结案。
5. 孩子通过首案后获得第一枚训练勋章，解锁城市地图。
6. 后续案件逐步进入疯狂动物城不同区域，并加入语文、英语课程。

待确认：

- 第一位出场导师是谁。
- 首页是否出现多个导师，还是首案只出现一位导师。
- 首案通过后解锁“城市地图”，还是先解锁“下一节训练课”。

## 3. 核心循环

MVP 必须跑通以下闭环：

1. 招募：首页建立“我要加入警官学院”的动机。
2. 入学：创建小警探身份。
3. 接案：导师给出第一项训练任务。
4. 学习闯关：完成数学任务，获得线索。
5. 线索板：孩子看到自己收集到的证据。
6. Boss 挑战：用综合题修复训练系统或击破干扰。
7. 结案：展示完成结果、XP、勋章和下一步目标。

设计原则：

- 每一步只出现一个主要目标。
- 每个训练题都要解释“为什么这是线索”。
- 错误反馈要像导师提示，不像考试批改。
- 首案只教会核心玩法，不追求内容数量。

## 4. 首个案件框架

案件定位：

- 类型：校园训练案。
- 学科：数学。
- 场景：警官学院训练场 / 指挥中心 / 路线训练室。
- 情绪：新生入学、训练系统小故障、导师带着孩子解决问题。
- 目标：让孩子完成一次完整破案闭环，获得第一枚数学训练勋章。

不做：

- 不做三学科混合。
- 不做真实犯罪、危险追捕或复杂嫌疑人关系。
- 不做长篇剧情。
- 不做高压限时惩罚。

## 5. 首案数学知识点候选

以下是下一轮需要项目负责人选择的内容。当前尚未确认。

| 候选 | 知识点 | 玩法想象 | 优点 | 风险 |
| --- | --- | --- | --- | --- |
| A. 方向与位置 | 东西南北、路线描述 | 在训练场按方向找标记、追踪路线 | 最像“警校训练”，游戏感强 | 需要设计清楚地图交互 |
| B. 有余数除法 | 平均分、商和余数 | 分配训练装备、证物分箱、警车座位 | 数学目标明确，适合 Boss 综合题 | 对部分孩子可能有难度 |
| C. 时分秒 | 读时间、经过时间 | 安排巡逻表、按时完成训练 | 生活感强 | 游戏刺激感较弱 |
| D. 测量 | 厘米、米、估测长度 | 测脚印、量训练路线、选工具 | 和侦探线索结合自然 | 线上交互需要处理测量表现 |

我的建议：A. 方向与位置。

原因：

- 校园训练案天然适合地图和路线。
- 孩子能通过“移动、找地点、判断方向”感到自己在破案。
- 比单纯计算更容易做成可视化闯关。

最终决定：待确认

## 7. 首案验收标准草案

待确认：

- 首案 8-12 分钟完成。
