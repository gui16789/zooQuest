# 游戏框架草案

状态：首案知识点与 Boss 形式已确认，具体剧情和导师待确认  
用途：定义“游戏像什么”，在页面设计和开发前先确定玩法骨架。

## 1. 已确认边界

- 世界观：疯狂动物城内部原型。
- 第一入口：疯狂动物城警官学院官网招募页。
- MVP 核心：完整破案学习闭环。
- MVP 主用户：小学二年级孩子优先。
- 首个完整案件：单学科案件。
- 首个案件学科：数学。
- 首个案件类型：校园训练案。
- 首案知识点：方向与位置。
- 首案 Boss 形式：混乱导航机器人。
- 首案方向难度：只考东、南、西、北。
- 首案地图形态：路线节点图。
- Boss 失败规则：无限重试 + 导师提示。
- 首案标题方向：导航机器人迷路案。
- 第一位导师：牛局长 / 牛队长。
- 首案通关后：解锁城市地图。
- 首案任务结构：4 个线索任务 + 1 个轻量推理选择 + 3 题 Boss 战。
- 首案结案奖励：XP + 第一枚勋章 + 城市地图解锁。
- 第一枚勋章：导航修复勋章。
- 城市地图首屏：展示 3 个区域，开放中央广场，锁定 2 个区域。
- 首案通关后引导：先看勋章，再前往城市地图。

## 2. 游戏主线草案

孩子第一次进入时，不是直接刷题，而是收到警官学院的新生招募邀请。

主线草案：

1. 孩子浏览警官学院官网，了解“新生探员招募”。
2. 孩子点击加入学院，创建自己的小警探档案。
3. 牛局长 / 牛队长欢迎新生进入学院训练场。
4. 学院发布第一项训练案件“导航机器人迷路案”：用方向与位置知识帮助机器人找回正确路线。
5. 孩子通过首案后获得第一枚训练勋章，并解锁城市地图。
6. 后续案件逐步进入疯狂动物城不同区域，并加入语文、英语课程。

待确认：

- 首页是否出现多个导师，还是首案只出现牛局长 / 牛队长。
- 首案通关后的城市地图首屏展示哪些区域。

## 3. 核心循环

MVP 必须跑通以下闭环：

1. 招募：首页建立“我要加入警官学院”的动机。
2. 入学：创建小警探身份。
3. 接案：导师给出第一项训练任务。
4. 学习闯关：完成数学任务，获得线索。
5. 线索板：孩子看到自己收集到的证据。
6. Boss 挑战：用综合题修复训练系统或击破干扰。
7. 结案：展示完成结果、XP、勋章和下一步目标。

设计原则：

- 每一步只出现一个主要目标。
- 每个训练题都要解释“为什么这是线索”。
- 错误反馈要像导师提示，不像考试批改。
- 首案只教会核心玩法，不追求内容数量。

## 4. 首个案件框架

案件定位：

- 标题：导航机器人迷路案。
- 类型：校园训练案。
- 学科：数学。
- 知识点：方向与位置。
- Boss：混乱导航机器人。
- 导师：牛局长 / 牛队长。
- 场景：警官学院训练场 / 导航训练室 / 校园路线地图。
- 情绪：新生入学、训练机器人发出错误指令、导师带着孩子修复训练路线。
- 目标：让孩子完成一次完整破案闭环，获得第一枚数学训练勋章，解锁城市地图。

不做：

- 不做三学科混合。
- 不做真实犯罪、危险追捕或复杂嫌疑人关系。
- 不做长篇剧情。
- 不做高压限时惩罚。

## 5. 首案数学知识点

已确认：方向与位置。

学习目标草案：

- 能识别东、南、西、北。
- 能根据简单方向指令在地图上移动。
- 能判断一个地点在另一个地点的哪个方向。
- 能读懂 2-4 步的简单路线。
- 能发现路线描述中的错误方向。

玩法原则：

- 每道题尽量使用地图、箭头、路标、训练点位。
- 题干短，优先使用“从 A 出发，向东走到 B”这类句式。
- 首案只使用东、南、西、北四个方向。
- 东北、西北、东南、西南留到后续进阶案件。
- 每个正确答案都转化为一个线索，例如点亮路标、修好导航芯片、找到训练徽章。

地图形态：

- 已确认使用路线节点图。
- 节点可以是训练场内的地点，例如报到台、路标塔、装备室、指挥屏、训练门、导航机器人站。
- 节点之间用清晰路线连接，每条路线标注或暗示方向。
- 地图需要比自由地图更可控，比 3x3 网格更有场景感。

## 6. 首案 Boss 形式

已确认：混乱导航机器人。

Boss 草案：

- 名称暂定：混乱导航机器人，案件标题使用“导航机器人迷路案”。
- 设定：它负责带新生完成训练路线，但方向芯片被打乱，总把“东”和“西”、“南”和“北”说反。
- 孩子任务：听/看机器人给出的错误路线，选择正确方向，帮助它恢复导航。
- Boss 失败表现：机器人绕圈、撞到训练路标、路线灯闪红。
- Boss 成功表现：训练路线点亮，机器人恢复正常，导师颁发第一枚勋章。
- 失败规则：答错后不惩罚，可无限重试，导师逐步给出更明确提示。

待确认：

- Boss 名称。
- Boss 外观风格。
- Boss 是否有轻量台词。
- 牛局长 / 牛队长在 Boss 战中的提示文案风格。

## 7. 首案验收标准草案

待确认：

- 孩子能在 2 分钟内从官网进入训练案。
- 首案 8-12 分钟完成。
- 首案包含 4-5 个数学线索任务 + 1 个 Boss 综合挑战。
- 每道题都给出导师提示和答案解释。
- Boss 战答错后允许无限重试，并给出导师提示。
- 孩子完成后能获得第一枚训练勋章。
- 首案结束后明确告诉孩子：城市地图已解锁，下一步将进入动物城办案。

## 8. 首案任务结构

已确认流程：

1. 剧情引入：牛局长 / 牛队长发布“导航机器人迷路案”。
2. 线索任务 1：识别东、南、西、北。
3. 线索任务 2：根据方向指令在路线节点图上移动。
4. 线索任务 3：判断某个训练点在另一个训练点的哪个方向。
5. 线索任务 4：找出机器人路线描述中的错误方向。
6. 轻量推理：判断导航机器人为什么迷路，或哪条路线描述最可疑。
7. Boss 战：3 道综合方向挑战，修复混乱导航机器人。
8. 结案奖励：获得 XP、第一枚训练勋章，解锁城市地图。

设计约束：

- 线索任务和 Boss 战都只使用东、南、西、北。
- 推理环节不做嫌疑人排除，只做一个简单原因判断。
- Boss 战答错不惩罚，允许无限重试并给导师提示。
- 结案奖励不使用星级评价作为核心反馈。
- 首案总时长目标仍为 8-12 分钟。

待确认：

- 4 个线索任务的具体题干和答案。
- 第一枚勋章名称与视觉方向。
- 城市地图解锁后的首屏区域数量。

## 9. 首案奖励与地图解锁

已确认：

- 第一枚勋章：导航修复勋章。
- 城市地图首屏展示：3 个区域。
- 首个开放区域：中央广场。
- 其他 2 个区域：锁定或待解锁。
- 通关后引导：先看勋章，再前往城市地图。

奖励页流程：

1. 显示牛局长 / 牛队长的结案鼓励。
2. 展示“导航修复勋章”获得动画或静态反馈。
3. 显示获得 XP。
4. 显示“城市地图已解锁”。
5. 主按钮：前往城市地图。

勋章视觉方向：

- 机器人头像或导航机器人轮廓。
- 四向箭头或发光路线。
- 警徽外形，强化学院奖励感。
- 颜色要明亮，避免像故障警告图标。

城市地图首屏：

- 中央广场：可进入，作为第一个城市区域。
- 区域 2：锁定，名称待确认。
- 区域 3：锁定，名称待确认。

待确认：

- 另外 2 个锁定区域选择哪些。
- 中央广场第二案的学科和案件方向。
- 城市地图首屏是否显示导师推荐任务。
