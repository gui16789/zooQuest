# 游戏框架草案

状态：首案知识点与 Boss 形式已确认，具体剧情和导师待确认  
用途：定义“游戏像什么”，在页面设计和开发前先确定玩法骨架。

## 1. 已确认边界

- 世界观：疯狂动物城内部原型。
- 第一入口：疯狂动物城警官学院官网招募页。
- MVP 核心：完整破案学习闭环。
- MVP 主用户：小学二年级孩子优先。
- 首个完整案件：单学科案件。
- 首个案件学科：数学。
- 首个案件类型：校园训练案。
- 首案知识点：方向与位置。
- 首案 Boss 形式：混乱导航机器人。

## 2. 游戏主线草案

孩子第一次进入时，不是直接刷题，而是收到警官学院的新生招募邀请。

主线草案：

1. 孩子浏览警官学院官网，了解“新生探员招募”。
2. 孩子点击加入学院，创建自己的小警探档案。
3. 导师欢迎新生进入学院训练场。
4. 学院发布第一项训练案件：用数学能力修复训练系统、收集线索、完成结案。
5. 孩子通过首案后获得第一枚训练勋章，解锁城市地图。
6. 后续案件逐步进入疯狂动物城不同区域，并加入语文、英语课程。

待确认：

- 第一位出场导师是谁。
- 首页是否出现多个导师，还是首案只出现一位导师。
- 首案通过后解锁“城市地图”，还是先解锁“下一节训练课”。

## 3. 核心循环

MVP 必须跑通以下闭环：

1. 招募：首页建立“我要加入警官学院”的动机。
2. 入学：创建小警探身份。
3. 接案：导师给出第一项训练任务。
4. 学习闯关：完成数学任务，获得线索。
5. 线索板：孩子看到自己收集到的证据。
6. Boss 挑战：用综合题修复训练系统或击破干扰。
7. 结案：展示完成结果、XP、勋章和下一步目标。

设计原则：

- 每一步只出现一个主要目标。
- 每个训练题都要解释“为什么这是线索”。
- 错误反馈要像导师提示，不像考试批改。
- 首案只教会核心玩法，不追求内容数量。

## 4. 首个案件框架

案件定位：

- 类型：校园训练案。
- 学科：数学。
- 知识点：方向与位置。
- Boss：混乱导航机器人。
- 场景：警官学院训练场 / 导航训练室 / 校园路线地图。
- 情绪：新生入学、训练机器人发出错误指令、导师带着孩子修复训练路线。
- 目标：让孩子完成一次完整破案闭环，获得第一枚数学训练勋章。

不做：

- 不做三学科混合。
- 不做真实犯罪、危险追捕或复杂嫌疑人关系。
- 不做长篇剧情。
- 不做高压限时惩罚。

## 5. 首案数学知识点

已确认：方向与位置。

学习目标草案：

- 能识别东、南、西、北。
- 能根据简单方向指令在地图上移动。
- 能判断一个地点在另一个地点的哪个方向。
- 能读懂 2-4 步的简单路线。
- 能发现路线描述中的错误方向。

玩法原则：

- 每道题尽量使用地图、箭头、路标、训练点位。
- 题干短，优先使用“从 A 出发，向东走到 B”这类句式。
- 不在首案引入过多方位扩展，东北/西北/东南/西南是否进入首案待确认。
- 每个正确答案都转化为一个线索，例如点亮路标、修好导航芯片、找到训练徽章。

待确认：

- 首案是否只考东南西北，还是加入东北/西北/东南/西南。
- 首案地图是 3x3 网格、自由地图，还是路线节点图。

## 6. 首案 Boss 形式

已确认：混乱导航机器人。

Boss 草案：

- 名称暂定：混乱导航机器人。
- 设定：它负责带新生完成训练路线，但方向芯片被打乱，总把“东”和“西”、“南”和“北”说反。
- 孩子任务：听/看机器人给出的错误路线，选择正确方向，帮助它恢复导航。
- Boss 失败表现：机器人绕圈、撞到训练路标、路线灯闪红。
- Boss 成功表现：训练路线点亮，机器人恢复正常，导师颁发第一枚勋章。

待确认：

- Boss 名称。
- Boss 外观风格。
- Boss 是否有轻量台词。
- 失败后是否允许无限重试，还是消耗提示卡。

## 7. 首案验收标准草案

待确认：

- 孩子能在 2 分钟内从官网进入训练案。
- 首案 8-12 分钟完成。
- 首案包含 4-5 个数学线索任务 + 1 个 Boss 综合挑战。
- 每道题都给出导师提示和答案解释。
- 孩子完成后能获得第一枚训练勋章。
- 首案结束后明确告诉孩子下一步会进入城市地图或下一项训练。
