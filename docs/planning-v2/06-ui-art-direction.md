# UI / 美术方向草案

状态：视觉方向待确认  
用途：统一页面设计、imagegen 资产、前端实现和后续验收标准，避免“高保真图好看但真实 UI 错位”的问题。

## 1. 已确认输入

来自前序规划的关键约束：

- 主用户：小学二年级孩子优先。
- 第一入口：警官学院官网招募页。
- 首案：导航机器人迷路案。
- 首案导师：牛局长 / 牛队长。
- 首案地图：训练场路线节点图。
- 首案奖励：导航修复勋章。
- 页面流程：官网首页 -> 创建小警探 -> 接案 -> 训练场线索任务 -> 独立线索板 -> 推理 -> Boss -> 勋章奖励 -> 城市地图。
- 线索任务：地图节点即任务入口。
- 真实交互必须可点击、可响应式、可维护。

## 2. 核心设计原则

### 2.1 真实 UI 优先

关键规则：

- 背景图不能承载关键文字。
- 按钮、题干、选项、输入框、进度、线索、地图节点状态必须由前端 DOM 实现。
- imagegen / 高保真图只负责场景、角色、道具、氛围，不负责最终交互文字。
- 如果图片里必须出现标识文字，只能是装饰性文字，不作为答题或导航依据。

原因：

- 小朋友使用时需要真实点击反馈。
- 页面需要适配桌面、平板、手机。
- 后续题库、课程、地图会扩展，不能每次重新出整张大图。

### 2.2 分层资产

每个页面资产应拆成以下层：

| 层级 | 内容 | 形式 | 是否可交互 |
| --- | --- | --- | --- |
| 背景层 | 学院大门、训练场、城市地图氛围 | PNG/WebP/JPG | 否 |
| 角色层 | 牛局长、导航机器人、头像 | 透明 PNG/WebP | 可作为按钮旁角色，但角色本身通常不承载功能 |
| 道具层 | 勋章、路线芯片、方向灯、路标 | 透明 PNG/WebP 或 SVG | 可作为线索卡内容 |
| UI 层 | 按钮、题干、选项、输入框、进度条 | HTML/CSS/React | 是 |
| 状态层 | 高亮、锁定、完成、错误、提示 | CSS/DOM | 是 |

禁止：

- 把完整页面 UI 生成成一张背景图，然后用热区点击。
- 把题干、答案、按钮文字画死在图片里。
- 用图片裁切模拟输入框或按钮。

## 3. 视觉风格候选

### 方案 A：绘本警校风

关键词：

- 温暖、清楚、可爱但不幼稚。
- 像儿童绘本里的警官学院。
- 场景有故事，UI 稳定易读。

适合：

- 二年级孩子。
- 学习 + 破案的结合。
- 长期内容扩展。

风险：

- 如果色彩太软，可能缺少闯关兴奋感。

### 方案 B：动画电影感

关键词：

- 丰富光影、城市纵深、角色戏剧性。
- 更接近动画电影海报和场景截图。

适合：

- 首页和关键剧情场景。

风险：

- 资产成本高。
- 容易让 DOM UI 与背景不融合。
- 如果画面太满，文字可读性下降。

### 方案 C：游戏化卡通 HUD

关键词：

- 明确按钮、进度条、地图标记、奖励反馈。
- 更像闯关游戏界面。

适合：

- 任务页、Boss 战、奖励页。

风险：

- 如果过度 HUD 化，会削弱学院故事感。

建议：

- 主风格采用 A：绘本警校风。
- 任务反馈使用 C 的游戏化组件。
- B 只用于少量大场景氛围，不作为整体实现方式。

## 4. 色彩方向草案

目标：

- 不做单一蓝色/紫色主题。
- 保持警校感，同时适合儿童。
- 不使用压抑深色大面积背景。

建议色彩角色：

| 用途 | 颜色方向 | 说明 |
| --- | --- | --- |
| 主色 | 警校蓝 | 用于导航、主按钮、标题强调 |
| 辅色 | 活力橙 / 徽章金 | 用于奖励、重要提示 |
| 成功 | 新芽绿 | 用于完成、路线点亮 |
| 警示 | 番茄红 | 只用于错误方向、机器人故障，不大面积使用 |
| 背景 | 暖白 / 浅天蓝 / 校园浅绿 | 保持明亮和低压力 |
| 文本 | 深墨蓝 / 深灰 | 保证阅读对比度 |

可访问性要求：

- 正文文字对比度目标不低于 4.5:1。
- 重要按钮不只依赖颜色，还要有文字或图标。
- 错误状态使用颜色 + 提示文字。

## 5. 字体与文字规则

目标：

- 二年级孩子能读。
- 家长也不觉得幼稚粗糙。

规则：

- 题干和按钮字体不小于 16px，移动端建议 17-18px。
- 题干每行不宜过长。
- 题干保持 20-45 字，复杂内容拆成导师提示。
- 不使用过度花哨字体作为正文。
- 标题可以更有童趣，但必须清楚。
- 不使用负字距。

## 6. 页面视觉规则

### 6.1 官网首页

首屏目标：

- 孩子 10 秒内知道“我要加入警官学院”。

资产建议：

- 学院大门或学院校园背景。
- 牛局长 / 牛队长欢迎新生。
- 真实 DOM 的标题、说明和主按钮。

禁止：

- 做成成人培训机构官网。
- 堆课程卖点长文。
- 用背景图里的文字当主要标题。

### 6.2 创建小警探

视觉目标：

- 像领取学员证，而不是注册表单。

资产建议：

- 学员证卡片。
- 3 个动物头像。
- 随机昵称按钮。

UI 规则：

- 昵称输入框真实可输入。
- 随机昵称按钮真实可点击。
- 头像选中态明显。

### 6.3 首案接案页

视觉目标：

- 牛局长发布训练任务，有入学考核感但不压迫。

资产建议：

- 牛局长半身透明角色图。
- 案件档案夹 / 训练任务板。
- 导航修复勋章预告。

UI 规则：

- 案件标题是真实文本。
- 奖励预告用真实组件 + 勋章图标。

### 6.4 训练场线索任务

视觉目标：

- 孩子看见一个可探索训练场，而不是题目列表。

资产建议：

- 训练场背景。
- 路线节点图。
- 报到台、装备室、路标塔、指挥屏、训练门、机器人站节点图标。

UI 规则：

- 节点是 DOM / SVG / Canvas 可点击元素，不画死在背景图里。
- 当前节点高亮。
- 已完成节点点亮。
- 未解锁节点变灰或上锁。
- 题干、提示、选项独立于背景。

### 6.5 独立线索板

视觉目标：

- 像小侦探整理证据。

资产建议：

- 线索板背景可以是木板/软木板/训练报告板。
- 4 个线索卡：方向灯、路线芯片 1、路线芯片 2、故障原因线索。

UI 规则：

- 线索卡真实可点击。
- 点击后显示一句短解释。
- 不做拖拽组合。

### 6.6 Boss 战

视觉目标：

- 有挑战感，但不恐吓孩子。

资产建议：

- 混乱导航机器人透明角色图。
- 3 段修复进度。
- 错误路线闪烁 / 路线灯红黄绿状态。

UI 规则：

- Boss 答错不惩罚。
- 提示明确出现。
- 进度条不是血条，更像“修复进度”。

### 6.7 勋章奖励页

视觉目标：

- 导航修复勋章是第一视觉焦点。

资产建议：

- 勋章大图。
- 路线灯点亮效果。
- 牛局长简短鼓励。

UI 规则：

- 主按钮是“前往城市地图”。
- XP 是次要信息，不抢过勋章。

### 6.8 城市地图

视觉目标：

- 孩子感觉“我从学院进入动物城了”。

资产建议：

- 城市地图背景。
- 中央广场开放区域。
- 2 个锁定区域。

UI 规则：

- 开放态、锁定态清楚。
- 锁定区域可以看见，但不能误点进入。
- 不一次展示太多未开放入口。

## 7. 首轮必需资产清单

MVP 首案最低需要：

1. 学院首页背景。
2. 牛局长 / 牛队长透明角色图。
3. 3 个小警探动物头像。
4. 训练场背景。
5. 6 个训练场节点图标。
6. 混乱导航机器人透明角色图。
7. 4 个线索图标。
8. 导航修复勋章。
9. 城市地图首屏背景。
10. 中央广场开放态图标 + 2 个锁定区域图标。

## 8. imagegen 资产生成规范

每次生成资产前必须明确：

- 资产用途：背景 / 角色 / 道具 / 勋章 / 图标。
- 是否需要透明背景。
- 是否允许包含文字。默认不允许。
- 输出比例。
- 需要避免的元素。

建议生成方式：

- 背景：无 UI、无按钮、无文字，保留构图安全区。
- 角色：透明背景，全身或半身，方向明确。
- 道具：透明背景，单一物体。
- 勋章：透明背景，居中，适合缩放。
- 地图：底图和可点击节点分开，不把节点状态画死。

## 9. 前端实现验收规则

每个页面完成后必须检查：

- 文字不和角色/背景重叠。
- 按钮真实可点击，不是图片热区。
- 移动端宽度下文字不溢出。
- 主要点击目标不小于 44px。
- 键盘焦点可见。
- 背景图加载失败时，核心任务仍可理解。
- 交互状态包括：默认、悬停/按下、完成、锁定、错误、提示。
