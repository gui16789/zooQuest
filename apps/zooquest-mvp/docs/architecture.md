# ZooQuest MVP 架构说明

新版 MVP 位于 `apps/zooquest-mvp`，与旧原型目录隔离。旧原型仅作为视觉参考，不再直接承载产品开发。

## 产品主线

一句话主线：孩子加入“动物城市警探学院”，收到“晨雾警报”，跟随三位导师在城市地图中破解学习案件，最终修复城市的知识灯塔。

MVP 只做第一章：

1. 学院官网：展示学院、三门课程、入学入口。
2. 入学建档：创建小探员档案。
3. 主线序章：晨雾警报出现，导师说明任务。
4. 城市地图：看到 1 个可玩案件和 3 个后续锁定章节。
5. 案件闯关：完成语文、数学、英语三条线索。
6. Boss 关：综合判断幕后干扰源。
7. 结案报告：展示 XP、勋章、错题复盘和下一章预告。

## 工程分层

```text
apps/zooquest-mvp/
  src/
    App.tsx              应用状态机和页面编排
    main.tsx             React 入口
    styles.css           独立视觉系统
    types.ts             MVP 数据类型
    data/story.ts        主线章节、案件、题目、导师配置
    domain/progress.ts   计分、等级、答题判断、进度计算
```

## MVP 原则

- 每个页面必须推进故事，不放无关后台控件。
- 题目是线索，不是孤立题卡。
- 首屏即为学院官网，不做营销空页。
- 所有角色为原创动物城市设定，避免未授权 IP。
- 先完成一个完整案件闭环，再扩展更多章节。
