# First Loop Asset Prompts

Status: generation pending  
Reference image: `apps/zooquest-mvp/design/references/key-assets-reference-v1.png`

These prompts define the first production asset batch for the first playable loop. Generated files must be saved into the project asset folders and treated as internal prototype assets until IP and licensing are resolved.

## Global Rules

- Style: cinematic 3D animated animal-city police academy look.
- Audience: Chinese second-grade children.
- Mood: warm, adventurous, clear, not scary.
- Do not copy or depict any existing named movie character.
- No readable text, no logos, no UI buttons, no watermarks.
- Key UI text, buttons, progress, answer options, and map node states must be implemented as DOM, not baked into images.
